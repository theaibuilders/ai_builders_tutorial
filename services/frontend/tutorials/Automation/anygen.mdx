## Workflow 1: Creating Intelligent Documents

The Document workspace is where ideas take shape. It is optimized for reports, blog posts, and strategic briefs.

### Step-by-Step
1. **Initiate the Project**: Select **Document** from the dashboard.
2. **Contextual Conversation**: Respond to AnyGen's initial questions.
   * *Example:* "Who is the audience?" or "What is the key takeaway?"
3. **Draft Generation**: AnyGen generates a structured draft based on the conversation.
4. **Refinement**: Use "Edit in Flow" tools to polish the text.

### Example: Edit in Flow
Highlight a paragraph and select a command from the floating menu:
* **Rephrase**: "Make this sound more professional."
* **Expand**: "Add more details about the Q3 financial results."
* **Shorten**: "Summarize this into a bulleted list."

One of AnyGen's most powerful features is converting written content into ready-to-present slides. It preserves the logic and structure of your document while adapting it for visual impact.

### How to Convert

2. Click the **Export to PPT** or **Generate Presentation** action.

## Workflow 3: Data Analysis with Verifiable Code

The Data Analysis module allows you to chat with your CSV files. It bridges the gap between raw data and actionable insights by generating the actual code used to calculate answers.

### The Process
1. **Upload Data**: Drag and drop your CSV file into the Data Analysis tab.
2. **Ask Questions**: Query your data in plain English.
   * *Query:* "What is the average revenue per region for the last quarter?"
3. **Verify the Output**: AnyGen displays the answer alongside the code it used to derive it.

### Code Generation Example
When you ask for a trend analysis, AnyGen generates and executes Python code similar to this context:

```python
import pandas as pd
import matplotlib.pyplot as plt

# Load the user uploaded dataset
df = pd.read_csv('sales_data.csv')

# Group by month and sum revenue
monthly_revenue = df.groupby('Month')['Revenue'].sum()

# Generate insight
print(f"Peak revenue occurred in {monthly_revenue.idxmax()} with ${monthly_revenue.max()}")
```
