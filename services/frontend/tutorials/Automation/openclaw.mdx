# OpenClaw: Build Your Personal AI Assistant

## What You're Building

In this tutorial, you'll deploy a production-ready **OpenClaw** AI assistant. By the end, your assistant will be able to search and scrape the live web (Bright Data), remember conversations across sessions (Mem9 + TiDB Cloud Zero), reason with a Southeast-Asia-tuned LLM (Agnes AI), and chat with you on Telegram — all running on a single Zeabur Dedicated Server.

## OpenClaw — Your AI Assistant Framework

OpenClaw is an open-source AI assistant framework that runs on your own infrastructure. It acts as a gateway between you and various AI models, skills, and communication channels. Think of it as a personal chief of staff that's always online, always learning, and ready to handle whatever you throw at it.

### Deploying OpenClaw on Zeabur

[Zeabur](https://zeabur.com) provides the hosting infrastructure for your OpenClaw instance. Using their one-click template, you can have a fully functional assistant running in under two minutes.

Open the one-click template and hit **Deploy**:

👉 [https://zeabur.com/templates/VTZ4FX](https://zeabur.com/templates/VTZ4FX?utm_source=luma)

You'll see a deployment form with three fields:

| Field | What to enter |
|||
| **Domain** | Pick a unique subdomain, e.g. `yourname-openclaw`. Your UI will be at `yourname-openclaw.zeabur.app` |
| **Enable Control UI** | Set to `true` so you can manage models and skills from the browser |
| **Zeabur AI Hub API Key** | Click **Generate** to create one automatically — this gives you access to bundled models at no extra cost |

Choose **Dedicated Server** as the server type, select the **OpenClaw** destination, and click **Confirm**.

![zeabur deploy form](/products/agentforge_openclaw/agentforge_openclaw_1.jpg)

Deployment takes roughly 60–90 seconds. Once the status turns green, open your domain URL in a browser and log in with the `OPENCLAW_GATEWAY_TOKEN` shown in the Zeabur **Instructions** tab.

## Telegram Bot Integration

Your assistant needs a channel to talk through. Telegram provides a reliable, real-time messaging platform that works on any device.

### Creating a Telegram Bot

Telegram bots are created through the official @BotFather service:

1. Open Telegram and message [@BotFather](https://t.me/BotFather)
2. Send `/newbot`
3. Pick a display name (e.g. *Agent Forge Bot*)
4. Pick a username ending in `bot` (e.g. `agentforge_hackathon_bot`)
5. Copy the token BotFather gives you (looks like `123456789:ABCdef...`)

### Connecting the Bot to OpenClaw

Add the bot token to your Zeabur environment:

Go to your OpenClaw service in Zeabur → **Variable** tab → add:

```bash
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
```

Restart the service. Then open the OpenClaw dashboard → **Channels** panel → click **Connect Telegram Bot**.

Your bot is now ready to receive and respond to messages.

### Agnes AI via ZenMux

[Agnes 1.5 Pro](https://zenmux.ai/sapiens-ai/agnes-1.5-pro) is a model optimised for OpenClaw, particularly tuned for Southeast Asian contexts. Access it through ZenMux's OpenAI-compatible gateway.

**Setting up Agnes AI:**

1. Sign up at [zenmux.ai](https://zenmux.ai) and create an API key
2. In Zeabur → **Variable** tab, add:

```bash
ZENMUX_API_KEY=your_zenmux_api_key_here
```

3. Open the Zeabur **File Management** tab and edit `/home/node/.openclaw/openclaw.json`. Replace the contents with this complete configuration:

```json
{

    "providers": {
      "zenmux": {
        "baseUrl": "https://zenmux.ai/api/v1",
        "apiKey": "${ZENMUX_API_KEY}",
        "api": "openai-completions",
        "models": [
          {
            "id": "sapiens-ai/agnes-1.5-pro",
            "name": "Agnes 1.5 Pro (ZenMux)",
            "reasoning": false,
            "input": ["text"],
            "cost": {
              "input": 1.0,
              "output": 4.0,
              "cacheRead": 0.1,
              "cacheWrite": 0
            },
            "contextWindow": 128000,
            "maxTokens": 8192
          }
        ]
      },
      "nosana": {
        "baseUrl": "{BASE_URL}",
        "apiKey": "${NOSANA_API_KEY}",
        "api": "openai-completions",
        "models": [
          {
            "id": "{NOSANA_MODEL_ID}",
            "name": "GLM-4.7 Flash Q4_K_M (Nosana)",
            "reasoning": false,
            "input": ["text"],
            "cost": {
              "input": 0,
              "output": 0,
              "cacheRead": 0,
              "cacheWrite": 0
            },
            "contextWindow": 128000,
            "maxTokens": 8192
          }
        ]
      }
    }
  },
  "agents": {
    "defaults": {
      "model": {
        "primary": "zenmux/sapiens-ai/agnes-1.5-pro",
        "fallbacks": ["nosana/{NOSANA_MODEL_ID}"]
      },
      "models": {
        "zenmux/sapiens-ai/agnes-1.5-pro": {}
      }
    }
  },
  "commands": {
    "native": "auto",
    "nativeSkills": "auto",
    "restart": true,
    "ownerDisplay": "raw"
  },
  "channels": {
    "telegram": {
      "enabled": true,
```

### Nosana — Decentralized GPU Compute

[Nosana](https://nosana.io) offers an alternative approach to running AI models — decentralized GPU infrastructure for AI inference. Instead of relying on centralized cloud providers, Nosana leverages a distributed network of GPUs, potentially offering cost savings and reduced vendor lock-in.

![nosana dashboard](/products/openclaw/nosana.png)

OpenClaw can connect to Nosana's inference endpoints using the same OpenAI-compatible gateway pattern. To use Nosana as a model provider:

1. Create an account at [nosana.io](https://nosana.io) and generate an API key
2. In Zeabur → **Variable** tab, add your Nosana credentials
3. Update your `openclaw.json` to include Nosana as a provider with the appropriate `baseUrl` and model IDs

This gives you another option for model inference alongside Zeabur AI Hub and ZenMux, letting you choose the infrastructure that best fits your needs.

## Bright Data — Web Search & Scraping

[Bright Data](https://brightdata.com) gives your agent the ability to search the web in real time and extract content from any page. This transforms your assistant from a static knowledge system into one that can access current information.

### Getting Bright Data Credentials

1. Log in to [brightdata.com](https://brightdata.com) and go to **Web Access** → **SERP API**
2. Create a new zone (or use the default one) and copy the **Zone name**
3. Go to **Account Settings** → **API Tokens** and copy your **API key**

![bright data dashboard](/products/agentforge_openclaw/agentforge_openclaw_4.jpg)

### Installing the Bright Data Skill

Message your Telegram bot to install the Bright Data skill using natural language:

> *"Install the Bright Data skill for web search."*

OpenClaw will automatically fetch and install the skill from ClawHub.

### Configuring Bright Data

In Zeabur → **Variable** tab, add:

```bash
BRIGHTDATA_API_KEY=your_bright_data_api_key
BRIGHTDATA_SERP_ZONE=your_zone_name
```

Restart the gateway by messaging your Telegram bot:

> */restart*

### Using Bright Data

Once configured, ask your bot to search the web:

> *"Search for the latest AI hackathon news in Singapore and summarise the top 3 results."*

The agent will use Bright Data's SERP API to search and summarise the articles.

## Mem9 — Persistent Memory

[Mem9](https://mem9.ai) replaces OpenClaw's built-in file-based memory with a proper vector-search-backed memory system. Your agent will remember user preferences and past conversations across sessions.

![mem9 dashboard](/products/agentforge_openclaw/agentforge_openclaw_5.jpg)

### Installing the Mem9 Skill

Message your Telegram bot to install the Mem9 skill using natural language:

> *"Read https://mem9.ai/SKILL.md and follow the instructions to install and configure mem9 for OpenClaw"*

OpenClaw will automatically fetch the skill instructions and guide you through the setup.

### Configuring Mem9

After installation, OpenClaw will provide you with a **MEM9 Space ID**. Save it to Zeabur → **Variable** tab:

```bash
MEM9_SPACE_ID=your_mem9_space_id
```

The skill automatically registers itself as a memory plugin, replacing OpenClaw's default `memory-core` slot. Send `/restart` to your Telegram bot to activate.

### How Memory Works

With Mem9 configured, your assistant remembers context across conversations. For example:

> *"Remember that my favourite programming language is Python and I'm interested in agentic AI."*

Then in a new session, ask:

> *"What do you know about me?"*

The agent will recall your preferences from the Mem9 store.

## TiDB Cloud Zero — Database

[TiDB Cloud Zero](https://zero.tidbcloud.com) gives your agent a disposable, MySQL-compatible database with built-in vector search — no sign-up, no config, provisions in milliseconds.

![tidb zero dashboard](/products/agentforge_openclaw/agentforge_openclaw_6.jpg)

### Provisioning a Database

Message your Telegram bot to set up TiDB Cloud Zero using natural language:

> *"Read https://zero.tidbcloud.com/SKILL.md and follow the instructions to create a database using TiDB Cloud Zero."*

OpenClaw will provision a database and return the connection string.

### Configuring the Database

Copy the `connectionString` from the agent's response. In Zeabur → **Variable** tab, add:

```bash
TIDB_CONNECTION_STRING=mysql://user:pass@gateway01.prod.aws.tidbcloud.com:4000/test
```

(Replace with your actual connection string.)

Send `/restart` to your Telegram bot to apply the changes.

### Using the Database

Your agent can now use SQL to store and query data. For example:

> *"Create a table to track the hackathon projects I've seen today, with columns for project name, team, and a short description."*

TiDB Zero databases last 30 days and include a free quota plus a hard $1 spending limit — plenty for a hackathon demo. If you want to keep the database afterwards, you can claim it in [TiDB Cloud](https://tidbcloud.com).

## Troubleshooting

- **OpenClaw won't start on Zeabur** — Ensure you selected **Dedicated Server** (not Shared). OpenClaw requires at least 2 vCPU and 4 GB RAM.

- **Telegram bot isn't responding** — Double-check `TELEGRAM_BOT_TOKEN` in the Variable tab. After adding or changing it, restart the service. Then click "Connect Telegram Bot" in the dashboard.

- **Bright Data skill not working** — Verify both `BRIGHTDATA_API_KEY` and `BRIGHTDATA_SERP_ZONE` are set. Send `/restart` to your Telegram bot after adding them.

- **Agnes AI model not appearing** — Confirm the `openclaw.json` file was saved correctly with valid JSON syntax. Validate the configuration and restart the service.

- **Mem9 not remembering across sessions** — Check that `MEM9_SPACE_ID` is set correctly. Make sure the mem9 skill was installed successfully via natural language and send `/restart` to your bot.

- **TiDB Cloud Zero connection failing** — Verify the connection string format is correct (`mysql://user:pass@host:4000/dbname`). Zero instances expire after 30 days — ask your agent to provision a new one if yours has lapsed.
