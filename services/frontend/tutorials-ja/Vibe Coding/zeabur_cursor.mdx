## ステップ 1：Cursor でプロンプトを使ってアプリを構築

まず、プロジェクトを生成しましょう。このチュートリアルでは、シンプルな Next.js ToDo アプリケーションを構築します。

Cursor でチャットパネルを開き、AI にアプリケーションの構築を依頼できます。

**プロンプト：** `can you build a simple next js based todo app`

AI が必要なファイルとフォルダ構造を生成します。完了したら、アプリをローカルで実行してテストできます。

```bash
npm run dev
```

これで `http://localhost:3000` でアプリが実行されていることを確認できます。

## ステップ 2：Zeabur 拡張機能をインストール

ワンクリックデプロイのプロセスを開始するには、まず Visual Studio Marketplace から Zeabur 拡張機能をインストールする必要があります。

1.  Cursor で **Extensions** ビューに移動します。
2.  「**Zeabur**」を検索します。
3.  **Install** をクリックします。

![zeabur-cursor-2-2](/products/zeabur/zeabur-cursor-2-2.webp)

## ステップ 3：ワンクリックでデプロイ

拡張機能をインストールすると、アクティビティバーに新しい Zeabur アイコンが表示されます。

1.  **Zeabur アイコン** をクリックします。
2.  **Deploy** ボタンをクリックします。

このアクションにより、ローカルコードがパッケージ化され、Zeabur のデプロイサービスに送信されます。

![zeabur-cursor-3](/products/zeabur/zeabur-cursor-3.webp)

ブラウザで Zeabur のウェブサイトを開いてプロセスを完了するよう促されます。**Open** をクリックします。

## ステップ 4：Zeabur の AI がプロジェクトを分析

ここで魔法が起こります。Zeabur にリダイレクトされると、AI がアップロードされたコードを自動的に分析します。言語、フレームワーク（この場合は TypeScript と Tailwind CSS を使用した Next.js）、必要なビルドステップを検出します。DevOps コードや設定ファイルを1行も書く必要はありません。

![zeabur-cursor-5](/products/zeabur/zeabur-cursor-5.webp)

## ステップ 5：新しいプロジェクトを設定

1.  **Create a new Zeabur project** をクリックします。

![zeabur-cursor-6](/products/zeabur/zeabur-cursor-6.webp)

2.  デプロイの **リージョンを選択** します。最適なパフォーマンスのために、ユーザーに最も近いリージョンを選んでください。
