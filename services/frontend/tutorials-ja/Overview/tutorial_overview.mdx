# AI Builders Tutorial プラットフォーム

AI Builders Tutorial へようこそ！ここでは、最新のツールを使って AI アプリケーションを構築するための包括的な実践型チュートリアルシリーズを提供しています 🚀

![ai-builders-tutorial-banner](/github_banner.webp)

## 学べること

各チュートリアルは実践的で、すぐに活用できる内容になっています：

• **簡潔で要点押さえ**: 各ツールの最重要概念をカバーし、すぐに始められるようにします
• **実践的な例**: すべての概念に実行可能なコードが含まれており、修正して試すことができます
• **ベストプラクティス**: 業界標準のアプローチと、避けるべきよくある落とし穴を学べます
• **段階的な複雑さ**: 基礎から始めて、高度な実装へと進みます

チュートリアルは Python または TypeScript で書かれており、簡潔な説明と実行可能なコード / ノートブックが含まれています。多くのチュートリアルにはコピーして使いやすいプロンプトやリファクタリングパターンがあり、実際のプロジェクトに直接応用できます。



## チュートリアルカテゴリ

以下はコンテンツ領域の簡単なマインドマップです。サイドバーでカテゴリを開くと、個々のツール、フレームワーク、ノートブックを探索できます。

### Vibe Coding
AI ネイティブエディタ（Cursor、Windsurf など）とワンクリックデプロイフローを活用し、単なる「チャット」利用を超えてイテレーションを加速させます — 生成されたファイルだけでなく、自分のコードを所有しましょう。

### Automation
AI + ワークフローエンジン（n8n、Zapier スタイルのオーケストレーション、バックグラウンドジョブ）を連携させ、イベントやパイプラインからエージェントやモデル呼び出しをトリガーします。

### Model Providers
幅広いプロプライエタリ & オープンモデル API を呼び出し、設定し、最適化します（レイテンシ、品質、フォールバック、コスト最適化）。

### Gateways
複数のプロバイダーを単一のインターフェースの背後に統一し、ルーティング、再試行、キャッシング、使用量追跡、グレースフルデグラデーションを実現します。

### Frameworks
エンドツーエンドのアプリケーションスキャフォールド：検索拡張、ツール呼び出しエージェント、マルチステップオーケストレーション、構造化出力、評価用ハーネス。

### Chat UI Framework
状態管理、ストリーミング、ツールフィードバックループを備えた、本番環境対応の会話型 & マルチモーダルインターフェースを迅速に構築します。

### Observability
LLM / エージェントの動作をステージング & 本番環境で計測、トレース、評価、デバッグします。スパン、プロンプト、スコア、回帰シグナルを収集します。

### Fine Tuning
ベースモデルをドメインのスタイルやタスク固有の内容に適応させます。データセット準備、パラメータ効率的手法、評価 & イテレーションをカバーします。

### Data & Memory
ベクトルデータベース、ハイブリッド検索、チャンク戦略、長期間メモリパターンを使用して、コンテキストを埋め込み、保存、取得します。

### Web Search
ライブ検索、クローリング、プロキシローテーション、SERP / 構造化抽出を統合して、レスポンスを最新情報に基づかせます。

### Browser Use
エージェントがライブな Web コンテキスト内でナビゲート、抽出、アクションを実行できるようにします（ヘッドレス & インタラクティブ）。リサーチ、QA、スクリプト化されたタスクに使用します。

### Audio / Realtime
低レイテンシ音声認識、ストリーミング合成、リアルタイム双方向エージェント体験。

### Image & Video
画像 & 動画メディアを生成 & 操作します（拡散モデル、動画パイプライン、アセット最適化、マルチモーダルグラウンディング）。
