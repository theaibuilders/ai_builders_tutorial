# Nosana x Mastra: 构建智能 AI 代理

本教程将指导您使用 Mastra 框架构建智能 AI 代理，并利用 Nosana 的去中心化 GPU 网络中的开源模型。

![nosana-mastra](/products/nosana/nosana_mastra.png)

## 理解核心技术

### 什么是 Nosana？

[Nosana](https://nosana.com/?utm_source=aibuilders) 是一个建立在 Solana 上的去中心化 GPU 市场，连接 GPU 拥有者与 AI 开发者。通过利用全球未充分利用的消费级 GPU，Nosana 提供比传统云服务提供商低至 85% 的成本的经济高效的 AI 推理计算能力。该网络通过 Docker 容器处理 AI 工作负载，提供动态定价和无缝集成以支持生产部署。

主要特点包括：
- **去中心化基础设施**：建立在 Solana 区块链上的点对点 GPU 共享
- **AI 推理专注**：专门优化用于运行训练好的 AI 模型
- **Docker 就绪**：使用任何 AI 框架部署容器化应用程序
- **性能验证**：所有 GPU 在部署前都经过严格基准测试

### 什么是 Mastra？

Mastra 是一个开源的 TypeScript 框架，旨在构建生产就绪的 AI 代理和工作流。由 Gatsby 团队创建，Mastra 提供了一个全面的工具包，包括代理、工作流、内存系统、工具集成和内置可观察性。该框架支持模型上下文协议（MCP），以实现无缝工具集成，并包括一个本地游乐场用于测试。

核心原语：
- **代理**：使用 LLM 和工具解决任务的自主系统
- **工作流**：基于状态机的编排，具有挂起/恢复功能
- **工具**：类型安全的函数，代理执行以与外部系统交互
- **内存**：持久的对话历史和语义回忆
- **MCP 集成**：用于连接外部服务的通用插件系统

### 在 Nosana 上部署 GPT-OSS 20B 模型

在配置代理之前，您需要在 Nosana 的基础设施上部署 GPT-OSS 20B 模型：

![nosana-template](/products/nosana/nosana-template.png)

1. 导航到 [Nosana Dashboard](https://nosana.com/dashboard?utm_source=aibuilders)
2. 使用您的 Nosana 账户登录
3. 转到 **推理** 部分
4. 点击 **部署新模型**
5. 从可用模型模板中选择 **GPT-OSS 20B**
6. 选择您首选的 GPU 配置（推荐：NVIDIA RTX 4090 或更高）
7. 点击 **部署** 并等待模型被配置（通常需要 2-5 分钟）
8. 部署完成后，复制 **API 端点 URL** - 它将类似于：
   ```
   https://YOUR_NOSANA_URL_ID.node.k8s.prd.nos.ci
   ```

### 配置环境变量

复制 `.env.example`，将其重命名为 `.env`，并使用 Nosana 端点配置您的环境变量：

```bash
# 对于 Nosana Ollama 端点与 GPT-OSS 20B
OLLAMA_API_URL=https://YOUR_NOSANA_URL_ID.node.k8s.prd.nos.ci/api
MODEL_NAME_AT_ENDPOINT=gpt-oss:20b
```

将 `https://YOUR_NOSANA_URL_ID.node.k8s.prd.nos.ci` 替换为您实际的 Nosana API 端点 URL，点击 `Open Service` 后（只需复制粘贴页面链接）。

## 构建您的第一个代理

### 创建自定义代理

Mastra 中的代理是将 LLM 与工具结合以完成任务的自主系统。创建一个新的代理文件：

```typescript
// src/mastra/agents/assistant.ts
import { Agent } from '@mastra/core/agent';
import { openai } from '@ai-sdk/openai';

export const assistantAgent = new Agent({
  name: '个人助理',
  instructions: `您是一个有帮助的个人助理，可以：
    - 回答有关各种主题的问题
    - 帮助管理任务
    - 提供建议
    
    在回答中始终保持简洁和准确。
    在需要时使用可用工具来完成任务。`,
  model: openai('gpt-4o-mini'),
  tools: {},
});
```

### 实现自定义工具

工具通过连接到外部 API 和服务来扩展代理的能力。创建一个用于获取数据的工具：

```typescript
// src/mastra/tools/index.ts
import { createTool } from '@mastra/core';
import { z } from 'zod';

export const searchTool = createTool({
  id: 'web-search',
  description: '在给定主题上搜索网络信息',
  inputSchema: z.object({
    query: z.string().describe('搜索查询'),
  }),
  outputSchema: z.object({
    results: z.string().describe('搜索结果摘要'),
  }),
  execute: async ({ context }) => {
    const { query } = context;
    const response = await fetch(
      `https://api.example.com/search?q=${encodeURIComponent(query)}`
    );
    const data = await response.json();
    
    return {
      results: data.summary || '未找到结果',
    };
  },
});

export const calculatorTool = createTool({
  id: 'calculator',
  description: '执行数学计算',
  inputSchema: z.object({
    expression: z.string().describe('要评估的数学表达式'),
  }),
  outputSchema: z.object({
    result: z.number(),
  }),
  execute: async ({ context }) => {
    const { expression } = context;
    try {
      const result = eval(expression);
      return { result: parseFloat(result) };
    } catch (error) {
      throw new Error('无效的数学表达式');
    }
  },
});
```

将工具添加到您的代理中：

```typescript
import { assistantAgent } from './agents/assistant';
import { searchTool, calculatorTool } from './tools';

export const enhancedAgent = new Agent({
  name: '增强助手',
  instructions: assistantAgent.instructions,
  model: openai('gpt-4o-mini'),
  tools: { searchTool, calculatorTool },
});
```
### 创建研究工作流
工作流通过控制流逻辑编排代理和工具执行的复杂序列。

```typescript
// src/mastra/workflows/research.ts
import { Step, Workflow, createWorkflow } from '@mastra/core/workflows';
import { z } from 'zod';
import { researchAgent } from '../agents/research';
import { writerAgent } from '../agents/writer';

const researchStep = new Step({
  id: 'research',
  execute: async ({ context }) => {
    const { topic } = context.triggerData;
    
    const result = await researchAgent.generate(
      `研究关于: ${topic} 的全面信息`
    );
    
    return { research: result.text };
  },
});

const writeStep = new Step({
  id: 'write',
  execute: async ({ context }) => {
    const research = context.getStepResult('research')?.research;
    
    const result = await writerAgent.generate(
      `使用此研究撰写详细文章: ${research}`
    );
    
    return { article: result.text };
  },
});

export const researchWorkflow = createWorkflow({
  name: 'research-and-write',
  triggerSchema: z.object({
    topic: z.string(),
  }),
})
  .then(researchStep)
  .then(writeStep)
  .commit();
```

以编程方式执行工作流：

```typescript
const result = await researchWorkflow.execute({
  triggerData: { topic: '量子计算' },
});

console.log(result.results.write.article);
```

### 添加代理内存

内存使代理能够在对话中保持上下文并回忆以前的互动。

```typescript
import { Agent } from '@mastra/core/agent';
import { Memory } from '@mastra/memory';

export const memoryAgent = new Agent({
  name: '内存启用助手',
  instructions: '您记得过去的对话并提供个性化的响应。',
  model: openai('gpt-4o-mini'),
  memory: new Memory(),
  tools: {},
});
```

在对话中使用内存：

```typescript
const response = await memoryAgent.generate(
  '我的名字是 Alex，我在金融行业工作',
  {
    memory: {
      thread: 'user-123',
      resourceid: 'conversation',
    },
  }
);

const followUp = await memoryAgent.generate(
  '我说过我的职业是什么？',
  {
    memory: {
      thread: 'user-123',
      resourceid: 'conversation',
    },
  }
);
```

评估帮助衡量和跟踪代理性能：

```typescript
import { createEval } from '@mastra/core';

const accuracyEval = createEval({
  name: 'response-accuracy',
  evaluate: async ({ output, expected }) => {
    const score = calculateSimilarity(output, expected);
    return {
      score,
      passed: score > 0.8,
      metadata: { output, expected },
    };
  },
});
```

## 最佳实践和提示

### 代理设计
- 编写清晰、详细的系统提示，定义角色和能力
- 从简单的代理开始，逐渐增加复杂性

- 提供描述性工具描述，以便更好地理解 LLM
- 在工具执行函数中实现适当的错误处理
- 使用 Zod 模式进行类型安全的输入/输出验证

### 性能优化
- 使用流式响应以获得实时用户反馈
- 对昂贵的操作实现缓存
- 限制 maxSteps 以防止无限循环
- 监控资源使用情况并优化效率
- 实现适当的日志记录和可观察性
