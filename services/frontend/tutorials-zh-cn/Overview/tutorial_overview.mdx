# AI Builders 教程平台

欢迎来到 AI Builders 教程！这是一个全面的、动手实践的教程系列，旨在使用现代工具构建 AI 应用程序 🚀

## 您将学习到的内容

每个教程都旨在实用且立即可应用：

• **简洁明了**：我们涵盖每个工具的最重要概念，以便您快速入门  
• **动手示例**：每个概念都包括可运行和修改的代码  
• **最佳实践**：学习行业标准的方法和常见的陷阱以避免  
• **逐步复杂性**：从基础开始，逐步深入到复杂的实现  

教程使用 Python 或 TypeScript 编写，配有简明的解释和可运行的代码/笔记本。许多教程包括便于复制的提示和重构模式，以便您可以直接将其应用到真实项目中。

## 教程类别

以下是内容领域的快速思维导图。打开侧边栏中的一个类别以探索各个工具、框架和笔记本。

### Vibe 编码
利用 AI 原生编辑器（Cursor、Windsurf 等）以及一键部署流程，超越简单的“聊天”使用，掌控您的代码，而不仅仅是生成的文件。

### 自动化
将 AI 与工作流引擎（n8n、Zapier 风格的编排、后台作业）连接，以从事件和管道触发代理或模型调用。

### 模型提供者
调用、配置和优化各种专有和开放模型 API（延迟、质量、回退、成本塑形）。

### 网关
通过路由、重试、缓存、使用跟踪和优雅降级，将多个提供者统一在一个接口后面。

### 框架
端到端的应用程序脚手架：检索增强、工具调用代理、多步骤编排、结构化输出、评估工具。

### 聊天 UI 框架
快速构建生产就绪的对话和多模态接口，具有状态管理、流式传输和工具反馈循环。

### 可观察性
在预发布和生产环境中对 LLM/代理行为进行仪器化、跟踪、评估和调试；收集跨度、提示、分数和回归信号。

### 微调
将基础模型调整为领域风格或任务特定；涵盖数据集准备、参数高效方法、评估和迭代。

### 数据与记忆
使用向量数据库、混合搜索、分块策略和长期记忆模式嵌入、存储和检索上下文。

### 网络搜索
集成实时搜索、爬虫、代理轮换和 SERP/结构化提取，以将响应基于当前信息。

### 浏览器使用
使代理能够在实时网络环境中导航、提取和执行操作（无头和交互式），用于研究、质量保证和脚本任务。

### 音频/实时
低延迟语音识别、流式合成和实时双向代理体验。

### 图像与视频
生成和处理视觉媒体（扩散、视频管道、资产优化、多模态基础）。
